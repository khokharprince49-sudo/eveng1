# Third-party and protocol notices

This project independently implements a small subset of the publicly documented Even Realities G1 BLE/text behavior. It does not include code copied from the proprietary Even Realities app.

Protocol/reference reading:
- `emingenc/even_realities_g1`, public community library, BSD 2-Clause license: https://github.com/emingenc/even_realities_g1
- `AGiXT/mobile`, public community G1 BLE protocol notes: https://github.com/AGiXT/mobile/blob/main/Even%20Realities%20G1%20BLE%20Protocol.txt

The above references are informational. No source file from either repository is vendored in this project.
